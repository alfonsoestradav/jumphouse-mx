# Jump House

Sitio web de **Jump House Trampoline Park** en Plaza Santa Catarina, Santa Catarina, Nuevo León.

Parque de trampolines: salto ilimitado, fiestas de cumpleaños y promociones de lunes a domingo.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Deploy en Vercel

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Contenido

Precios, horario y datos de contacto salen de Google Maps, Facebook e Instagram del negocio. Las promociones pueden cambiar.
